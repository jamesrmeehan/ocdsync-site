Privacy Policy for OCDSync

OCDSync is a personal-use application. It reads event data from a spreadsheet and uses it to:

  • Create or update events in the user's own Google Calendar
  • Generate a calendar feed URL that the user can subscribe to from Windows Outlook or Apple Calendar

OCDSync does not share, sell, or transmit any data to third parties. Data accessed via the Google Calendar API is used solely to perform the syncing described above, on behalf of the account owner.

This application is intended for personal use by its developer and is not offered as a public service.
